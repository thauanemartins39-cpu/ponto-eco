# Projeto Ponto Eco

Site estático com comentários locais de exemplo.

## Como funciona
- Os comentários ficam salvos só no navegador usando `localStorage`.
- Cada aparelho mantém seus próprios comentários.

## Para testar localmente

1. Abra o arquivo `index.html` no navegador ou use um servidor local simples.
2. Entre na página de diretrizes e adicione comentários.

## Observação

Os comentários são apenas exemplos e não sincronizam entre aparelhos.
